How to play

  1. Add at least three people. Use everyone's actual names, and let each person choose Low, Medium, or High comfort.
  2. Start the countdown. Everyone receives one randomly selected, age-friendly social mission at their comfort level or easier.
  3. Invite phones (optional). Tap Invite and enable phone joining. Players scan the QR code, choose their name, and request access. The host approves every request. New players can request to join before the round starts. Or pass the host phone around as before.
  4. Privately open your card. Each approved phone sees only its own mission. Offline, tap your name on the host and hide your card before passing the device.
  5. Play naturally. Everyone tries to complete their task before the same timer reaches zero. Tap Mark done if you wish. Refresh is available only if the host enabled it.
  6. Play again. New round reuses the players and levels and deals new tasks. Edit players returns to setup.

Connection note: Passing the host phone works offline. QR joining uses PeerJS Cloud for connection signaling and WebRTC for data between phones; the host tab and an internet connection must remain available. Approving requests controls who receives a card. The host itself still has access to all missions. DeepSeek is separate and optional; your API key never goes to players.
